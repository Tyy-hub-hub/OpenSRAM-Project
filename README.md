# OpenSRAM-Project

> 本项目旨在通过开源协作的方式，学习和研究静态随机存取存储器（SRAM）的设计原理与实现方法。

## 📅 项目进度

- **[202X-XX-XX]**: 项目初始化，创建仓库和基本目录结构。完成开源SRAM编译器调研。
- **[未来计划]**: 开始6T-SRAM单元的Verilog建模。

## 🎯 项目目标

1.  学习SRAM的基本工作原理，包括读、写、保持操作。
2.  使用Verilog HDL对6T-SRAM单元进行行为级建模。
3.  搭建测试平台（Testbench）并对SRAM单元进行功能仿真。
4.  将多个SRAM单元组合成一个小型的存储阵列。

## 📂 项目结构

- `docs/`: 项目相关文档和参考资料。
- `src/`: Verilog 源代码目录。
- `sim/`: 仿真测试文件和脚本。
- `reports/`: 每周的项目进展报告。

## 🔬 技术调研：OpenRAM

为了加速项目启动，我们调研了开源SRAM编译器 **OpenRAM**。

*   **项目简介**: OpenRAM 是一个获奖的开源SRAM编译器，能够根据用户配置的规格（如位宽、深度）自动生成SRAM的物理布局、网表、时序和功耗模型[[source_group_web_1]]。
*   **核心功能**: 它采用模块化设计，支持多种工艺平台（如 Skywater 130nm），可以生成完整的SRAM架构图，包括位单元阵列、地址解码器、灵敏放大器等[[source_group_web_2]]。
*   **对我们的启发**: 我们可以通过学习 OpenRAM 生成的代码和结构，快速理解一个完整SRAM宏的组成，而不是从零开始摸索。这为我们后续的自主设计提供了宝贵的参考。
